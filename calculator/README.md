# Command-Line Calculator

A Python command-line calculator with advanced math operations, input validation and a calculation history.

## Features
- Basic: addition, subtraction, multiplication, division, modulo
- Advanced: power, square root, nth root, factorial, logarithm (any base), natural log, percentage
- Trigonometry: sin, cos, tan (angles in degrees)
- Calculation history (view / clear)
- Error handling: division by zero, negative roots, invalid input, undefined values

## Requirements
Python 3.8+ (no external libraries).

## Run
```bash
python calculator.py
```

## Example
```
Choose an option: 6
  First number : 2
  Second number: 10
  => 2 ^ 10 = 1024
```
